## 🔒 About My GitHub Activity

> [!NOTE]
> **Most of my professional work isn't public — by design.**
> The majority of the products I build are developed under client and company agreements, so their source code is **confidential** and lives on **private, self‑hosted Git servers** rather than on GitHub.
> As a result, my public contribution graph reflects only a small slice of my day‑to‑day engineering. What you see here is mainly open‑source libraries, side projects, and experiments — the bulk of my commits go to production codebases behind company doors.
>
> Happy to walk through architecture, decisions, and results from that work in a conversation. 🤝

> [!TIP]
> **About my teaching repositories**
> Some public projects here were built specifically for **recorded courses and live teaching sessions**. In those, the code is intentionally kept simple and step‑by‑step so students can follow along — which means production‑grade architecture is sometimes deliberately set aside in favor of clarity.
> They're best read as **learning material**, not as a reflection of how I structure production systems.
